# Herramienta-Hevequi-SDD
Herramienta web para controlar los ingresos y salidas de la bodega logística de Hevequi. Trazabilidad por ítem con código QR, estados de recepción, validación y entrega, 4 roles (Coordinador, Supervisor, Auxiliar, Comprador), tablero y cuadre. Hecha en HTML, CSS y JavaScript con Supabase.
